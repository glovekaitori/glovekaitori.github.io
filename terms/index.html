第1条（目的と適用）

この規約は、G-LOVE（以下「本サービス」）による非対面の買取について、お客様と当社の権利義務を定めるものです。

本サービスの申込み・ご利用には、この規約が適用されます。お申込みの際に同意の確認を行い、同意いただいた方にのみ本サービスを提供します。

個別の売買契約書・委任状にこの規約と異なる定めがある場合は、個別の書面の定めが優先します。

第2条（用語）

「当社」とは、買主である株式会社グローブ（以下「買主」）と、受付・ご連絡・ブランド管理を行う株式会社マネージメントアドバイザーズ（以下「受付担当会社」）をいいます。

「売主」とは、品物を売却しようとするご本人（法人の場合は法人）をいいます。「代理人」とは、売主から委任状により手続きを任された方をいいます。

「品物」とは、査定・買取のために当社へお送りいただく物品（付属品を含む）をいいます。

「査定額」とは、品物ごとに当社が提示する買取価格をいいます。

第3条（売買の当事者）

売買契約の買主は株式会社グローブです。受付担当会社は、買主の委託を受けて受付・ご連絡・お手続き画面の運営を行い、自ら品物を買い受けることはありません。

第4条（ご利用いただける方）

次のすべてに当てはまる方がご利用いただけます。

  1. 18歳以上の方（18歳未満の方からの買取はお受けしません）
  2. 日本国内に住所があり、住民票等で確認できる方
  3. 品物の所有者、または所有者から処分の権限を正当に与えられている方
  4. 第26条の反社会的勢力に当てはまらない方

判断能力に不安がある、ご家族などから取引の中止を求められているなど、取引の継続が適切でないと当社が判断した場合は、取引をお断りし、品物をお返しすることがあります。

第5条（お申込みとご連絡）

お申込みの際は、正確で最新の情報を入力してください。内容に変更があった場合は、速やかにお知らせください。

当社からのご連絡は、お申込み時にお選びいただいた方法（メール等）とお手続き画面で行います。

ご連絡にお返事がないことを、査定額の承認や売買の合意として扱うことはありません。

第6条（ご本人確認）

当社は、古物営業法に基づき、買取の前に売主（代理人の場合は代理人ご本人も）の住所・氏名・職業・年齢を、同法に定める非対面の方法で確認します。

確認が済まない場合、確認書類に不備がある場合、または申告内容と確認結果が一致しない場合は、買取を行いません。

買取代金は、確認した売主ご本人名義の口座へお振込みします（第17条）。

第7条（代理人による手続き）

代理人による手続きは、代理人が作成した電子委任状（任せる範囲と期限を記載したもの）の内容を売主が確認し、署名した場合に限ります。代理人ご自身の本人確認が済むまで、委任は有効になりません。代理人が売主の連絡先を入力した場合は、当社が代理人を通さない方法で売主ご本人に確認するまで、委任は有効になりません。

代理人が委任の範囲内で行った手続きは、売主が行ったものとして効力を生じます。範囲を超える手続きは受け付けません。

売主は、いつでもお手続き画面から委任を撤回できます。撤回の前に代理人が行った手続きの効力は失われません。

代理人は、正当な委任を受けていることを当社に対して保証し、委任の不存在や範囲の誤りにより当社に損害を与えた場合はその責任を負います。

第8条（売主の表明と保証）

売主は、お申込みから売買契約の締結までの各時点で、品物について次のことを表明し、保証します。

  1. 売主の所有物であるか、処分する正当な権限があること
  2. 盗品、遺失物、横領・詐欺その他の犯罪により得た物、またはその疑いのある物ではないこと
  3. ブランド・メーカーの真正品であり、偽造品・模倣品・コピー品ではないこと
  4. ローンの未払い・所有権留保・担保権・差押えなど、第三者の権利が付いていないこと
  5. 品目・ブランド・型番・素材・金の品位・石の種類・改造や修理の有無など、申告した内容が事実であること
  6. 法令により売買が禁止・制限されている物ではないこと

第9条（お取扱いできない品物）

次の品物はお取扱いできません。お預かり後に判明した場合は、第15条・第16条・第21条の扱いとなります。

  1. 第8条の表明と異なる品物（盗品等・偽造品・第三者の権利が付いた品物など）
  2. 銃砲刀剣類、薬機法・ワシントン条約・その他の法令により売買が禁止または制限される物
  3. 公序良俗に反する物、衛生上・安全上お預かりが適切でない物
  4. その他、当社が買取を適切でないと判断した物

第10条（発送・集荷・梱包）

当社が案内する方法（梱包キット・ご自身での発送・直接集荷）で品物をお送りいただく場合、送料は当社が負担します。当社が案内していない方法（特別な保険・時間指定便など）を選ばれた場合の費用は、お客様のご負担です。

梱包は、品物が破損しないよう適切に行ってください。運送中の事故は、運送会社の約款に従って処理し、当社は運送会社への請求に協力します。

高額品の送り方は、事前に担当者にご相談ください。直接集荷は、お品物や場所などを拝見して個別にご案内します。

第11条（お預かりと検品）

当社は、品物の到着後、内容・点数・状態を確認し、お手続き画面またはメールでお知らせします。

査定のため、開封、動作確認、計測、重量・金の品位の測定など、必要な範囲で品物を取り扱うことに同意いただきます。品物の価値を下げないよう注意して行います。

真贋や価値の判断のため、秘密保持を約束した専門の鑑定機関・専門家に照会することがあります。この場合も、お客様のお名前など品物の判断に不要な情報は伝えません。

当社に故意または過失がない限り、査定に必要な作業に伴う変化（未開封品の開封など）について責任を負いません。

第12条（査定）

査定は無料です。査定額は品物ごとに提示します。

お申込み時や写真での目安は概算であり、実物の確認結果によって変わることがあります。

査定額は、通知日から14日間を有効期間とします。有効期間を過ぎると、お手続き画面から回答・締結はできません。売却をご希望の場合は担当者にご連絡いただければ、改めて査定額をご案内します。相場が大きく変動した場合などは、有効期間内でも再査定をお願いすることがあり、その場合は改めてご承認をいただきます。

第13条（売買契約の成立）

売買契約は、買主が査定額を通知したこと（買主からの申込み）に対し、売主（または承認と署名を任された代理人）がお手続き画面で売るお品物を選び、確認の項目にチェックを入れて電子署名した時に成立します。

電子署名の際には、売買契約書の全文をお示しし、署名の日時・署名者・文書の確認値（改ざん検知のための値）を記録します。成立した契約書は、お手続き画面でいつでも確認・保存できます。

売主は、品物ごとに「売る」か「返却」を選べます。お返事がないこと、または期限が過ぎたことにより、売買契約が成立することはありません。

第6条のご本人確認が済んでいない間は、売買契約を締結できません。

第14条（所有権の移転と危険の負担）

品物の所有権は、買主が買取代金の支払いを完了した時に、売主から買主へ移転します。

当社が品物をお預かりしている間に、当社の責めに帰すべき事由により品物が滅失・損傷した場合は、第24条に従って補償します。

第15条（盗品・遺失物などが判明した場合）

売買契約の成立後であっても、次のいずれかに当たる場合、買主は催告なく売買契約を解除できます。

  1. 品物が盗品、遺失物、その他犯罪により得た物であると判明したとき
  2. 警察から品物について照会・品触れ・保管命令を受けたとき
  3. 被害者または遺失主から品物の回復を求められたとき
  4. 品物に第三者の権利（所有権留保・担保権・差押えなど）があると判明したとき

古物営業法により、古物商が買い受けた盗品・遺失物は、盗難・遺失の時から1年以内であれば被害者・遺失主が無償で回復を求めることができます。当社はこの求めや警察の指示に従い、品物を被害者・警察へ引き渡します。売主にはお返ししません。

前2項の場合、売主は受け取った買取代金の全額を、当社が請求した日から14日以内に返還してください。売主が事情を知らなかった場合も同様です。

売主が事情を知っていた、または知らなかったことに重大な過失がある場合は、売主は、解除によって当社に生じた損害（調査・輸送・被害者への対応などの費用で合理的な範囲のもの）も賠償してください。

当社は、不正品の疑いがある場合、古物営業法に基づき直ちに警察へ申告します。売主は、警察の捜査と当社の調査に協力してください。

第16条（偽造品・模倣品や申告との重大な違いが判明した場合）

売買契約の成立後に、品物が偽造品・模倣品であると判明した場合、または品目・ブランド・型番・素材・金の品位・石の種類・改造や非純正部品の有無などが申告や査定の前提と大きく異なると判明した場合、買主は売買契約を解除できます。

前項の場合、売主は受け取った買取代金の全額を、当社が請求した日から14日以内に返還してください。売主が事情を知らなかった場合も同様です。違いが一部のお品物に限られるときは、そのお品物の代金に限ります。

前2項の扱いは、売買契約の成立日から1年以内に判明した場合に限ります。ただし、売主が事情を知っていた場合は、この期間の制限はありません。

偽造品・模倣品は、法令上お返しできない場合や警察の指示がある場合を除き、返還金を受け取ったあとで売主へお返しします（送料は売主のご負担）。売主が所有権を放棄された場合は、当社が法令に従い廃棄します。

当社は、判明した根拠（鑑定機関の所見・メーカーの回答など）をお示しし、売主のご意見を伺います。売主と当社の合意により、契約の解除に代えて、正しい内容に基づく再査定額で精算することもできます。

売主が偽造品と知りながら売却した場合、当社は損害の賠償を求めるほか、刑事告訴を含む法的な措置をとることがあります。

第17条（買取代金のお支払い）

買取代金は、売買契約の成立後、当社所定の確認を経て、売主ご本人名義の金融機関口座へお振込みします。法人の品物は法人名義の口座です。振込手数料は買主が負担します。

口座の名義が売主と一致しない場合、代理人や第三者の名義の口座を指定された場合などは、担当者が確認を終えるまでお支払いを保留します。

お振込みが完了したら、メールでお知らせします。お客様の口座情報の誤りによりお振込みできなかった場合、組戻しの手数料はお客様のご負担となることがあります。

第18条（返還の遅延）

第15条・第16条などにより売主が当社へ金銭を返還する場合に、期日までに返還されないときは、期日の翌日から返還の日まで、年14.6%の割合による遅延損害金をお支払いいただきます。

第19条（辞退と品物のご返却）

売買契約の成立前であれば、査定へのご回答の後でも、お手続き画面からいつでも無料で辞退できます。売らないことを選んだお品物は、当社の負担でお返しします（偽造品などの扱いは第16条によります）。

査定額の通知から7日を過ぎてもお返事がない場合は改めてご連絡し、14日を過ぎた場合はご返却の予定をお知らせします。お返事がないことを承認として扱うことはありません。

ご返却の品物は、確認したご住所へお送りします。到着から7日以内に、内容・状態の違いをお知らせください。

ご不在・受取拒否などで品物が当社に戻り、当社からの連絡に30日以上お返事がない場合は、改めて処分の予告をお送りします。予告から30日を過ぎてもご連絡がない場合、当社は品物を処分することがあります。

第20条（契約成立後のお取消し）

売買契約の成立後は、売主のご都合による解約はお受けできません。ただし、お振込みの前で、当社が同意した場合はこの限りではありません。

  3. 中身のない発送、買取の意思のない申込みの繰り返しなど、業務を妨げる行為

第22条の2（AIによる鑑定の補助と、お品物の写真の提供）

当社は、査定を早く正確に行うため、お送りいただいたお品物の写真を、AI（人工知能）による鑑定の補助に使います。売主・代理人は、この規約に同意することで、次の内容で写真を外国の第三者へ提供することに同意したものとします。

  1. 提供先：Google LLC（所在国：アメリカ合衆国）が提供する Gemini API（無料版）
  2. 提供する情報：お品物の写真のみ。撮影場所・撮影日時・機種などの付加情報は消して送ります。お名前・ご連絡先・受付番号・金額は送りません。
  3. 目的：品物の特定（ブランド・型番など）、状態の確認、真贋の確認点の洗い出し、相場の参考情報の作成。結果は当社の担当者の参考にだけ使い、査定額は担当者が実物を確認して決めます。
  4. 提供先での扱い：無料版のため、送った写真は Google のサービスの改善に使われ、Google の担当者が内容を確認する場合があります。
  5. アメリカ合衆国の個人情報の保護に関する制度：連邦レベルの包括的な個人情報保護法はなく、連邦取引委員会法などの分野別の法律と州法（カリフォルニア州消費者プライバシー法など）により保護されています。詳しくは個人情報保護委員会が公表している「外国における個人情報の保護に関する制度等の調査」をご覧ください。
  6. 提供先が講じる措置：Google のプライバシーポリシーと Gemini API の利用規約に定める安全管理の措置によります。

写真に人の顔・ご住所・送り状・書類などが写らないようにしてお送りください。写っていた場合、その写真はAIに送らないよう努めますが、確実に除けるとは限りません。

写真をAIに送ることを望まない場合は、お手続き画面のチャットまたはお問い合わせでお申し出ください。お申し出の後は送りません（すでに送った写真は取り消せません）。お申し出によって査定やお取引で不利に扱うことはありません。

第23条（記録の保存）

当社は、古物営業法に基づく取引の記録、ご本人確認の記録、電子署名と操作の記録を、法令で定める期間保存します。これらは削除・変更できない形で保存し、法令に基づく照会に応じて提供することがあります。

運送中の事故は第10条によります。付属品の欠品、自然な劣化、もともとの故障は補償の対象外です。

この規約のどの定めも、消費者契約法その他の法令によりお客様に認められた権利を制限するものではありません。

本サービスの試験運用中に作成されたお申込み・契約は試験用の記録であり、売買の効力を持ちません。
